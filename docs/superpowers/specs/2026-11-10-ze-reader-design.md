# ZE Reader 首版设计

日期：2026-11-10

状态：范围已确认，完整设计待用户审阅；本文件不表示功能已经实现。

## 目标与已确认范围

用户希望将“阅读顺序与分支定位”和 Paper Reader Translate Bridge 合并为一个 Zotero 插件，并逐步替代 Ethereal Style。用户已选择先完成核心首版。

首版交付一个可分享、可从文件安装的 `ze-reader.xpi`，提供：

1. 已读勾选、阅读顺序、分支定位。
2. 网页阅读器与 Translate for Zotero 之间的翻译桥接。
3. 已打开 PDF 的列表，以及标签页分组保存与恢复。
4. 跨文献的笔记与标注汇总、搜索与原文跳转。
5. 根据已有标注的颜色或标签生成文献矩阵。

首版是核心阅读工作流的替代版本。阅读时长统计、期刊指标、被引次数、嵌套标签、附件预览、页边批注、笔记反向链接、AI 自动分析、Style 私有数据导入不在本轮范围内。原文跳转是从汇总内容回到来源，不宣称实现“查看某条标注被哪些笔记引用”的反向链接功能。

所有新增能力独立实现，不依赖 Ethereal Style 的运行时、授权或受保护模块。翻译继续依赖用户已配置可用的 Translate for Zotero 及其外部服务。

## 当前项目事实

- Git 仓库为 `ZE/`，当前分支为 `plugin`。
- 现有阅读路线插件位于 `plugins/reading-columns/`，版本为 `0.2.0`；工作区根目录下还有同内容的独立副本。
- 阅读路线插件已用标签 `阅读状态-已读` 保存状态；路线标签及分类键有现成预设。
- Bridge 位于 `zotero-bridge/`，版本为 `0.2.1`，使用 `POST /paper-reader/translate`。
- 网页服务从自己的 `bridge.token` 读取凭据，并调用该本机端点。
- Bridge 当前在构建时把令牌写入 XPI，不能直接作为可分享安装包。
- 本次源码检查时，阅读路线与 Bridge 的 18 项现有 Node 测试通过；这不是新版本的验收结果。

## 安装、身份与兼容性

统一插件名称为 **ZE Reader**，首版版本为 `0.3.0`，源码位于 `plugins/ze-reader/`。

复用 `reading-route-columns@local.example` 作为插件 ID，安装新 XPI 时升级现有阅读路线插件。保留现有列的数据键、已读标签、路线规则和布局迁移偏好，避免重复列与状态迁移。原有“阅读顺序”“分支定位”仍默认隐藏，并尊重用户之后的列显示选择。

旧的独立 Bridge 使用另一插件 ID。升级说明要求停用旧 Bridge；统一插件不自动卸载其他扩展。启动时检查旧 Bridge 是否启用以及翻译端点是否已注册，避免因扩展启动顺序不同而漏检。若有冲突，翻译模块不注册或覆盖该端点，设置中显示处理方法，其他模块照常工作。停用时只撤销本插件拥有的端点。

兼容目标为现有代码声明的 Zotero `10.0.x`，通过实际加载后才能标记为已验证。发现缺少所需 API 时，提示具体不可用功能；不把未经验证的 Zotero 7、8、9 或后续版本写为兼容。

安装包只包含清单、脚本、界面、样式和本地化资源，不包含令牌、文库内容、机器路径或测试文件。首版采用手动安装更新，不配置未经部署的真实更新服务。

## 界面与模块边界

提供统一的“ZE Reader”工作台入口，放在 Zotero 工具菜单中；工作台采用独立窗口，分为“标签页”“笔记与标注”“文献矩阵”三个视图。独立窗口避免替换 Zotero 原有侧边栏，也避免与当前聊天面板争用位置。

插件设置提供翻译桥接的令牌配置、连接状态和功能说明。翻译凭据只显示已配置状态，输入采用密码控件。

运行时代码按职责分开：

| 模块 | 职责 | 主要边界 |
| --- | --- | --- |
| 生命周期 | 启停、窗口与资源注册、功能状态 | 调用各模块的启动与清理方法 |
| 阅读路线列 | 复用已有三列和已读写入逻辑 | 仅用户切换已读状态时写入条目 |
| 翻译桥接 | 校验请求并转发翻译 | 保持既有 HTTP 路径和请求/响应结构 |
| 标签页分组 | 保存引用、恢复 PDF、切换标签页 | 通过适配层使用 Zotero 标签页和 Reader API |
| 内容汇总 | 按范围读取笔记与标注 | 返回与 UI 无关的结构化数据 |
| 文献矩阵 | 按规则将标注分配到矩阵 | 只处理已有内容，不生成研究结论 |
| 工作台与设置 | 展示、筛选、用户操作与错误反馈 | 不直接实现数据持久化逻辑 |

对 Zotero 内部接口的访问集中在适配层。优先使用现有插件接口和原生打开方法；确需读取内部标签页列表时集中封装，并覆盖 API 缺失的失败路径。

## 阅读路线与已读状态

沿用当前 `plugins/reading-columns/reading-columns.js` 的功能和测试行为：

- 勾选与取消只新增或移除 `阅读状态-已读`，不改变其他标签。
- 保存失败恢复原状态并提示；同一条目的连续保存按顺序处理。
- 普通文献与独立 PDF 可标记；子附件与子笔记不重复保存状态。
- 阅读路线仍按当前分类匹配，不用第一条路线标签猜测分支。
- 未配置分类或无匹配路线时路线列留空。
- 不根据停留时长、翻页或打开 PDF 自动标为已读。

首版保留现有路线预设，不额外增加路线编辑器。旧独立插件源码与构建入口可作为兼容资料保留，统一版维护在新目录，文档明确推荐的新安装包。

## 翻译桥接与令牌

保持网页服务的调用协议：请求包含 `token` 和 `text`；成功响应包含 `text`。继续拒绝含 Origin 的浏览器直连请求、空文本、非字符串文本及超过 800 字符的输入，且在鉴权通过前不调用翻译服务。

统一 XPI 不内置令牌。用户在设置中选择现有 ZE 安装目录内的 `bridge.token` 文件导入，或手工输入其内容。读取操作只读取明确选择的文件；不扫描用户目录，不在界面、日志、错误信息或安装包中输出凭据。

令牌保存到 Zotero 本机偏好，不通过 Zotero 数据同步。首次未配置时翻译接口返回明确的未配置错误，其他功能仍可使用；修改令牌后下一次请求使用新值，无需重新打包。

保留 Translate for Zotero 尚未就绪、外部翻译失败的可区分错误。设置页显示本地配置及翻译插件可用状态；真实联网测试由用户点击触发，发送固定、可见的测试短句。

Bridge 原有独立构建脚本保留兼容，新增统一构建不能调用该脚本把令牌嵌入安装包。首版不要求重写网页服务器或将 Python 阅读器打包进 XPI。

## 标签页列表与分组

工作台列出发起操作的 Zotero 主窗口中已打开的 PDF 标签页，支持搜索标题和切换到对应标签页。用户可把当前 PDF 集合保存为命名组，并恢复、重命名或删除已保存的组。

持久化数据使用有版本号的 Zotero 本机偏好；组内保存 `{libraryID, attachmentKey}`、显示标题及顺序，不保存易失的 tab ID、文档对象或 PDF 内容。相同附件按文库与附件键去重。

恢复分组时按保存顺序打开尚未打开的附件，复用已有标签页，不关闭用户当前打开的其他文献。阅读页码沿用 Zotero 自己的阅读状态，不承诺同步或覆盖网页阅读器的页码。

附件已删除、无权限或文件缺失时跳过并显示汇总结果，其他附件继续恢复。空组名、重复组名和损坏配置给出明确提示，不静默覆盖已有分组。组在本机重启后保留，不宣称跨设备同步。

## 笔记与标注汇总

范围分为“所选文献”和“当前列表”。默认使用所选文献；无选择时使用当前列表，并在视图中明确显示范围与文献数量。切换范围和点击刷新后重新读取；不把用户未打开的其他文库自动纳入检索。

将选中的子附件或笔记归一到其父文献；独立 PDF 和独立笔记按自身展示。同一父文献只处理一次。汇总可见且未删除条目下的笔记和 PDF 标注，包括正文、评论、颜色、标签、来源文献及页码信息。

提供关键词搜索、笔记/标注类型筛选，以及标注颜色与标签筛选。首版搜索采用普通文本匹配，不引入查询语言。内容分页或分批展示；较大范围显示加载状态。切换范围后，过期的读取结果不能覆盖新视图。

笔记内容转换为纯文本摘要展示，不执行笔记 HTML，不加载其外部资源。图片与墨迹标注保留类型、评论和来源跳转，不尝试 OCR 或伪造文本。

点击笔记打开 Zotero 原生笔记；点击标注优先使用附件与 annotation ID 定位。仅在已有可靠位置数据时退回页码定位；区分页码标签和 PDF 物理页索引，缺少位置时只打开附件并提示，不猜测页码。

## 文献矩阵

与汇总视图共用明确的文献范围。每行是一篇文献，列由用户定义的名称与匹配规则组成，例如把某个颜色命名为“方法”，或匹配某个标注标签。

每个规则首版只匹配一个颜色或一个精确标签；多个列规则可引用同一条标注。同一单元格保留所有匹配的标注文本与评论，并带回到来源的链接。空单元格显示“无匹配标注”，不自动补写结论。

提供颜色规则与标签规则的简单配置界面，保存到版本化本机偏好；不要求用户手写 JSON。以原始标注颜色值匹配，不把颜色自动解释为固定学术含义。

支持复制当前矩阵为 Markdown 表格，正确转义表格分隔符与换行，并保留 Zotero 来源链接。首版不自动创建或覆盖 Zotero 笔记，也不向 AI 或外部服务发送汇总内容。

## 错误处理与资源清理

- 单个模块初始化失败时记录不含凭据的错误并在状态中提示，其余模块继续初始化。
- 原生列接口、标签页接口或翻译插件不可用时，显示功能级错误，不伪装为成功。
- 关闭工作台或切换范围后取消未完成视图更新；捕获异步读取与打开失败。
- 停用、升级、卸载时移除本插件菜单、列、监听、计时器、偏好页注册与自有端点，关闭本插件工作台。
- 清理不关闭原生 PDF 标签页，不删除已读标签、笔记、标注或保存的分组配置。
- 不自动停用 Ethereal Style。完成验收后用户可以自行停用并比较工作流。

## 实施位置

- 新目录 `plugins/ze-reader/`：清单、生命周期、功能模块、界面、设置、本地化与构建脚本。
- `tests/` 或统一插件目录下：模块行为、生命周期、构建产物与兼容测试。
- `package.json`：将统一插件测试加入现有测试入口。
- `README.md` 和统一插件 README：安装、旧插件升级、令牌导入、首版功能与限制。
- `.gitignore`：仅按交付需要开放统一插件的明确公开构建产物，继续忽略令牌及其他私有 XPI。

实施不改动 `papers/`、当前 FABESA 文献、实际文库数据或当前阅读状态。

## 验收标准

1. 一个 XPI 可升级现有阅读路线插件，清单和压缩包检查通过，重复构建一致，产物不含凭据与文库内容。
2. 保留已读标签保存、失败恢复、子条目排除、分支匹配与布局偏好测试；既有 18 项检查继续通过。
3. 未配置、鉴权失败、非法输入、浏览器来源、翻译插件未就绪、翻译失败与成功请求均有行为测试；验证端点冲突与清理所有权。
4. 分组保存、恢复、附件去重、重启持久化、跨文库同键区分、缺失附件和损坏配置均有测试。
5. 汇总范围、父子归一、笔记文本处理、筛选、跳转与过期异步结果均有测试。
6. 矩阵按颜色或标签匹配、空结果、多个标注、多个附件、Markdown 转义及真实来源链接均有测试。
7. 验证启停和重载不会重复注册列、菜单、监听或端点，也不会清除文库内容。
8. 在可用的 Zotero 10.0.x 中实际验证安装、工具菜单、三个工作台视图、翻译配置与停用；记录具体版本、结果与未能完成的验证，不把模拟测试视为真实 UI 验证。
