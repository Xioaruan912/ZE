# ZE Reader First Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付一个统一 XPI，保留已读与路线列、翻译桥接，并新增 PDF 标签页分组、笔记与标注汇总、文献矩阵。

**Architecture:** 保留现有阅读路线源文件作为唯一实现，由统一构建复制进 XPI。新增脚本以 `var ZE模块名` 导出工厂，通过生命周期协调器注入 Zotero 适配层与本机偏好存储；工作台只调用这些接口，不直接持久化数据或访问内部标签页列表。

**Tech Stack:** Zotero 10.0.x bootstrap JavaScript、原生 XHTML/CSS、Python 3 标准库 ZIP 构建、Node 22 内置 test/assert/vm；不新增运行时依赖。

**Spec:** `docs/superpowers/specs/2026-11-10-ze-reader-design.md`（用户已确认）。

## Global Constraints

- 统一插件名称为 **ZE Reader**，首版版本为 `0.3.0`，源码位于 `plugins/ze-reader/`。
- 复用 `reading-route-columns@local.example` 作为插件 ID。
- 兼容目标为现有代码声明的 Zotero `10.0.x`，通过实际加载后才能标记为已验证。
- 保持网页服务的调用协议：请求包含 `token` 和 `text`；成功响应包含 `text`。
- 继续拒绝含 Origin 的浏览器直连请求、空文本、非字符串文本及超过 800 字符的输入，且在鉴权通过前不调用翻译服务。
- 统一 XPI 不内置令牌。令牌保存到 Zotero 本机偏好，不通过 Zotero 数据同步。
- 恢复分组时按保存顺序打开尚未打开的附件，复用已有标签页，不关闭用户当前打开的其他文献。
- 同一单元格保留所有匹配的标注文本与评论，并带回到来源的链接。空单元格显示“无匹配标注”，不自动补写结论。
- 清理不关闭原生 PDF 标签页，不删除已读标签、笔记、标注或保存的分组配置。
- 实施不改动 `papers/`、当前 FABESA 文献、实际文库数据或当前阅读状态。

## Review Focus

1. 旧 Bridge 比统一插件晚启动：按扩展启用状态预先发现冲突，不靠端点当前是否存在判断；Task 3 覆盖。
2. 两个文库中的附件键相同：分组、汇总与矩阵仍分别保留；Tasks 4、5、6 覆盖。
3. PDF 显示页码为罗马数字或位置 JSON 损坏：只使用有效物理索引回退，不猜测跳转页；Task 5 覆盖。
4. 用户快速切换范围或关闭工作台：迟到的异步结果不能更新旧视图；Task 7 覆盖。
5. 首选项损坏或来自未知未来版本：给出提示，用户明确替换前保留原始内容；Task 2 覆盖。

共享记录采用如下结构；标题、文本与标识分开保存，所有集合以 `libraryID + ':' + key` 去重：

```text
AttachmentRef = {libraryID: number, attachmentKey: string, title: string}
Group = {name: string, attachments: AttachmentRef[]}
Rule = {name: string, kind: 'color'|'tag', value: string}
Source = {kind: 'note'|'annotation', libraryID: number, itemKey: string,
          attachmentKey?: string, annotationKey?: string, pageIndex?: number}
Paper = {id: string, libraryID: number, key: string, title: string}
Record = {id: string, paperID: string, kind: 'note'|'annotation', text: string,
          comment: string, color: string, tags: string[], pageLabel: string,
          annotationType: string, source: Source}
Snapshot = {papers: Paper[], records: Record[], warnings: string[]}
ModuleState = {state: 'ready'|'unconfigured'|'conflict'|'unavailable'|'error', message: string}
```

`Source.itemKey` 始终是源笔记或源标注的键；`attachmentKey` 只在确有 PDF 附件时设置。物理页索引为零起点非负整数，不从 `pageLabel` 推断。所有新模块的纯逻辑用工厂和依赖注入，测试不启动真实 Zotero、不访问用户文库。
