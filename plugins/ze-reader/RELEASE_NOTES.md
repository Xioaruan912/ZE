ZE Reader 0.4.4，支持 Zotero 10.0.x。

- 新图标：打开的书页与阅读路线分支，透明背景。
- 接入 Zotero 原生插件自动更新，更新清单带 SHA-256 校验。
- 保留全局“编辑／完成编辑”、阅读顺序默认降序、分支定位、已读、鼠标悬浮 PDF 预览与滚轮翻页、内部标签精简。

首次从下方下载 `ze-reader.xpi`，在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」安装并重启。0.4.3 及更早版本使用占位更新地址，需要手动安装本版一次；此后在启用“自动更新插件”且可连接 GitHub 时，Zotero 可检查并安装后续版本。

源码、图标、构建脚本与更新清单均位于仓库 `plugin` 分支的 `plugins/ze-reader/`。
