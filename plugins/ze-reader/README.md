# ZE Reader 0.4.3

面向 Zotero 10.0.x，在原生文献列表和条目信息区提供阅读辅助，不需要独立工作台。

| 功能 | 用法 |
| --- | --- |
| 已读 | 点击复选框标记或取消，保存为 `阅读状态-已读` 标签，可随 Zotero 数据同步 |
| 阅读顺序 | 默认显示序号，通过列表上方统一“编辑”按钮开启输入，默认排序为降序 |
| 分支定位 | 默认显示文字，通过同一个“编辑”按钮输入自己的定位，如 `核心 · 标准模型下的构造`；未自填时沿用标签和预设映射 |

已读适用于普通文献和独立 PDF；子笔记、子附件不显示复选框。保存失败会恢复状态并提示。路线列需要当前分类与既有密码学路线预设及标签匹配；具体规则见 [阅读路线说明](../reading-columns/README.md)。两列默认隐藏，右键文献列表表头即可勾选显示。

阅读顺序与分支定位默认只读，所有单元格不再放置编辑按钮。在文献列表上方、搜索框左侧有一个“编辑”按钮，点击后两列统一变为输入框，按钮变为“完成编辑”。编辑期间 Enter 或离开输入框保存，Esc 仅取消当前输入；可以继续修改其他行。“完成编辑”会等待当前输入及正在进行的保存，再恢复全表文字展示。切换分类、关闭窗口或重启后回到只读状态；切换分类前的当前输入保存到原分类对应的分支。未配置路线的分类中全局按钮禁用；子笔记和子附件不提供输入框。每个主窗口独立控制编辑状态。

阅读顺序可输入 1–99，自动补为两位数；清空后保存可移除当前分支的顺序标签。已有标签的阶段、简称会保留；首次编号使用“自定”阶段和文献标题。保存失败恢复原序号并提示。首次点击阅读顺序表头排序时默认降序（大序号在前），再次点击可升序。升级时若当前正按阅读顺序升序排列，会一次性改为降序；随后手动选择的升序会保留，其他列的排序不被替换。

分支定位接受不超过 120 字符的单行内容，Enter/移开焦点保存、Esc 取消，清空后显示路线标签对应的默认定位（如有）。默认定位来自标签中的阶段和代码预设的分支/序号映射，不会分析论文内容。无路线或定位标签时留空，提示“填写定位”。自填内容保存为当前分支的 `阅读定位-分支名-内容` 标签，可以随 Zotero 数据同步；不会改写原顺序标签的序号或简称。修改阅读顺序后仍保留手填定位。它同样仅在已配置路线的分类中启用。

## PDF 悬浮预览

在文献列表把鼠标停到论文或 PDF 条目上约 350 毫秒，即弹出本机 PDF 首页，无需按键；提前离开会取消触发。移入弹窗可用滚轮向下翻到下一页、向上返回上一页，也可点击翻页按钮，或“打开 PDF”进入正式阅读器并定位到当前预览页。滚轮翻页支持像素、行、页三种事件单位，累积触控板细小位移，翻页间隔至少 180 毫秒以减轻连续事件跳页；横向手势及 Ctrl/Command 修饰滚轮不翻页。悬停编辑按钮或输入框不触发预览。

离开条目及弹窗约 220 毫秒后关闭；Esc、点击外部、滚动文献列表或窗口失焦也会关闭。翻页按钮会在弹窗显示期间定期同步原生阅读器状态，页码以实际显示页为准。多个 PDF 附件优先使用首选附件中的本机 PDF；未下载或已缺失时尝试其他本机 PDF，否则显示提示，不自动下载。预览使用 Zotero 的只读临时阅读器，不添加标签、笔记、标注或正式 PDF 标签页。

## 标签显示精简

右侧条目的标签区默认收起以 `阅读顺序-`、`阅读状态-`、`阅读定位-` 开头的内部标签，研究主题标签照常显示。“显示内部标签（数量）”按钮可随时展开，再次点击收起。正在编辑的标签保持可见，避免输入过程中突然消失。

此功能仅改变右侧标签区的显示，不删除或重命名标签。左侧原生标签筛选器保持原有行为；停用插件后恢复原显示。

## 安装

1. Zotero → 工具 → 插件 → 齿轮 → 从文件安装插件，选择 [ze-reader.xpi](ze-reader.xpi)。
2. 完全退出并重新启动 Zotero。
3. 在文献列表表头右键，勾选“已读”“阅读顺序”“分支定位”。
4. 需要修改路线信息时，使用列表上方搜索框左侧的“编辑／完成编辑”按钮。

沿用 `reading-route-columns@local.example`，可覆盖 0.3.x 或旧阅读路线插件，保留已读标签、路线标签和列偏好。没有独立工作台或 ZE Reader 设置页，也不需要翻译插件、令牌和网页服务。更新仍采用手动安装 XPI。

## 从 0.3.0 移除的内容

PDF 标签页分组、笔记与标注汇总、文献矩阵、翻译桥接及其工作台、设置入口已从源码和安装包移除。旧版保存的本机偏好不再读取，升级不清除这些数据；文库中的笔记、标注与标签不受影响。此修改仅涉及 ZE Reader 桌面插件，仓库中独立网页阅读器及旧 Bridge 的兼容源码另行保留。

## 构建与检查

在仓库根目录执行：

```powershell
npm.cmd run build:plugin
npm.cmd test
python -m unittest discover -s tests
```

输出为 `plugins/ze-reader/ze-reader.xpi`。只打包 manifest、bootstrap、runtime、共享阅读列、悬浮预览及标签显示脚本六个文件；不含独立网页或设置资源。验证范围见 [VALIDATION.md](VALIDATION.md)。
