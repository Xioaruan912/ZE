# ZE Reader 0.3.2 精简版

面向 Zotero 10.0.x，只保留文献列表中的三列：

| 功能 | 用法 |
| --- | --- |
| 已读 | 点击复选框标记或取消，保存为 `阅读状态-已读` 标签，可随 Zotero 数据同步 |
| 阅读顺序 | 在输入框中填写当前分类对应的路线序号，如 `02`，可直接修改 |
| 分支定位 | 显示当前文献的阶段和子路线，如 `奠基 · ABE构造主线` |

已读适用于普通文献和独立 PDF；子笔记、子附件不显示复选框。保存失败会恢复状态并提示。路线列需要当前分类与既有密码学路线预设及标签匹配；具体规则见 [阅读路线说明](../reading-columns/README.md)。两列默认隐藏，右键文献列表表头即可勾选显示。

阅读顺序可输入 1–99，自动补为两位数；按 Enter 或离开输入框保存，Esc 恢复原值，清空后保存可移除当前分支的顺序标签。已有标签的阶段、简称会保留；首次编号使用“自定”阶段和文献标题。保存失败恢复原序号并提示。未配置路线的分类、子笔记和子附件不提供输入框。

## 安装

1. Zotero → 工具 → 插件 → 齿轮 → 从文件安装插件，选择 [ze-reader.xpi](ze-reader.xpi)。
2. 完全退出并重新启动 Zotero。
3. 在文献列表表头右键，勾选“已读”“阅读顺序”“分支定位”。

沿用 `reading-route-columns@local.example`，可覆盖 0.3.0、0.3.1 或旧阅读路线插件，保留已读标签、路线标签和列偏好。没有独立工作台或 ZE Reader 设置页，也不需要翻译插件、令牌和网页服务。更新仍采用手动安装 XPI。

## 从 0.3.0 移除的内容

PDF 标签页分组、笔记与标注汇总、文献矩阵、翻译桥接及其工作台、设置入口已从源码和安装包移除。旧版保存的本机偏好不再读取，升级不清除这些数据；文库中的笔记、标注与标签不受影响。此修改仅涉及 ZE Reader 桌面插件，仓库中独立网页阅读器及旧 Bridge 的兼容源码另行保留。

## 构建与检查

在仓库根目录执行：

```powershell
npm.cmd run build:plugin
npm.cmd test
python -m unittest discover -s tests
```

输出为 `plugins/ze-reader/ze-reader.xpi`。只打包 manifest、bootstrap、runtime 和共享阅读列脚本四个文件。验证范围见 [VALIDATION.md](VALIDATION.md)。
