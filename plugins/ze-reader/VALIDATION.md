# ZE Reader 0.4.0 验证记录

保留已读与可编辑阅读顺序；新增分支定位编辑、PDF 悬浮预览及右侧标签区精简。工作台与翻译桥接保持移除。

- 安装包严格包含六个脚本/清单文件，不含工作台、设置、翻译桥接及其运行时资源。
- 从实际 XPI 加载 bootstrap，验证三列注册、原生增强模块加载、窗口释放/重新加载和完整卸载；运行时不得访问翻译端点或设置面板接口。
- 构建检查涵盖同插件 ID 升级、0.4.0 版本、确定性构建、打包源码一致及无本机凭据。
- 已读保存、失败回退、原标签保留、路线映射与窗口计时器仍由既有测试覆盖。
- 阅读顺序新增直接输入，覆盖原有路线信息保留、添加/清除、非法输入拒绝、失败回退、Enter/失焦保存、Esc 取消、切换分类时锁定原分支、与已读写入串行执行。
- 分支定位测试覆盖自填内容优先、清除后回退、无序号条目、跨分支隔离、非法输入、写入失败回退，以及直接编辑交互。
- PDF 预览测试覆盖 Alt 延迟、旧请求丢弃、离开/关闭/释放取消、仅本机 PDF、明确失败提示、浏览器初始化取消、迟到 Reader 的释放、真实主列表行 ID 的事件连接、从首页翻页与显式打开。
- 标签显示测试覆盖内部前缀、普通主题保留、展开/收起、动态增改、编辑中保持可见、多标签区隔离、停用恢复；此模块不访问 Zotero 条目写入 API。
- 本机已安装 Zotero 10.0.8 源码核对：ItemTree 的 `item-tree-main-row-N` 行 ID、原生 `tags-box` 的 `tagName` 属性，以及 `Reader.openPreview()` 返回的只读临时阅读器接口。源码核对与 Node 替身测试不等同于原生界面测试。
- 完整回归：105 项 Node 测试、70 项 Python 测试全部通过。统一 XPI 与共享阅读列兼容包均已重新构建。

本次不使用 computer use，原生界面由用户自行安装测试。0.3.0 的原生测试记录属于旧版本；不能用它声称 0.4.0 已在用户环境验证。右侧标签精简不影响左侧原生筛选器；其他 Zotero 版本及与 Style 等插件同时调整同一区域的兼容性需要自行验证。
