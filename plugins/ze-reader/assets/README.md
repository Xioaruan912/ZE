# ZE Reader 图标

`icon.png` 是插件使用的透明 PNG 原图。深蓝书页承载蓝绿分支路径，表达阅读顺序与研究分支；32、64、128 像素展示由 Zotero 按需缩放同一原图。使用内置图像生成工具制作，没有调用外部 CLI 或在源码中配置图像服务密钥。

A single bold, elegant geometric emblem integrating two open book pages with a clean branching path ending in two simple circular route nodes. Flat vector-like geometry, calm scholarly character, minimal shapes, generous clear space, optical symmetry, exceptionally legible at 32 pixels. Restrained deep ink-blue with one clear teal accent, strong contrast. Center the mark on an actual transparent background. Square composition, tightly framed with a small consistent safety margin. No letters, no text, no captions, no watermarks, no mockup, no shadows, no ornamental details. Deliver only one icon, not a sheet of options.
